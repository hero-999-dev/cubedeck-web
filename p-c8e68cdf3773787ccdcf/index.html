1. Install

From the release zip

  1. Download CubeDeck-<version>.zip from the repository (root folder or the Releases page).
  2. Unzip it anywhere. You should end up with a folder containing manifest.json.
  3. Open your browser's extension page: chrome://extensions, edge://extensions or opera://extensions.
  4. Turn on Developer mode.
  5. Click Load unpacked and pick the unzipped folder.
  6. Open YouTube and reload the tab. A row of small square icons appears in the top bar, to the left of the search box.

Updating: download the newer zip, replace the folder, then press the reload arrow on the extension card and refresh the YouTube tab.

Manifest V3, no build step, no dependencies. The whole thing is plain JavaScript, HTML, CSS and a PowerShell script that draws the PNG icons.

2. How it works — mind map

Read it clockwise: the popup decides which widgets exist, the content script builds the icon row and keeps it in sync with the page, each widget then either adds something to YouTube or hides part of it, and a few of them pull data from public endpoints.

5. How hiding works

Every hiding widget is one call to the same factory. It injects a single <style> element into <head> and removes it again when switched off. Nothing is deleted from the page.

hideSectionWidget({
  name: 'HideComments',
  iconPrefix: 'ch',
  storageKey: 'ch-hidden',
  styleId: 'ch-style',
  css: 'ytd-comments, ytd-live-chat-frame, #chat-container { display: none !important; }',
  titles: { hidden: 'chOn', visible: 'chOff', inactive: 'chIdle' },
});

Why a stylesheet, not DOM removal

YouTube re-renders whole sections on every in-app navigation. A removed node comes back seconds later; a CSS rule keeps working with no observer and no re-run.

Why links, not headings

Sidebar headings are translated, so they cannot be matched. Every block is recognised by a link only it contains — /premium, /feed/you, /@handle — which is language-independent.

The one rule that needs JavaScript. A finished stream carries no badge; its only trace is the phrase "Streamed 3 days ago". On channel pages that phrase sits in an aria-label and CSS can match it — but in search results and the watch-page sidebar it exists only as text, and CSS cannot match text. So HideLive also runs a small scanner: it reads the metadata line of each card, marks the matches with data-ct-past-stream="1" and lets the stylesheet hide that attribute. The scanner only runs while HideLive is on, only re-checks cards that actually changed, and pauses while the tab is in the background.

6. Masthead layout algorithm

YouTube's top bar is a space-between flex row, so every pixel added on the left pushes the search box right. The icon row cancels its own footprint with a negative margin and sits in the empty space that is already there. Three rules, in order:

  1. All icons fit that gap at a comfortable size → the search box does not move.
  2. They do not → the row takes real space and the search box slides right. Icons never shrink below 28 px; the box moves instead.
  3. Whatever empty space is left between the last icon and the input is then clawed back, so the icons always end up beside the search box rather than stranded next to the logo.

Two details that cost a round of debugging each: the row needs z-index, because the neighbouring flex item's box starts 40 px before the input inside it and was swallowing clicks on the last icon; and the "am I covering the input" check has to compare against the same padding the layout aims for, or it fires on the layout's own target and shoves the search box every time.

7. Settings panel

Language

Six shipped languages plus about forty more. Anything outside the six is translated once through a public translation endpoint and cached in local storage, so the panel opens instantly afterwards. Widget names stay as they are — a name is a name.

Hide parts of YouTube

  • Sidebar — the left panel in all of its forms, plus the hamburger.
  • Voice search — the microphone button.
  • Create / upload button.
  • Notifications bell.
  • Video description — hides the description text, disables clicks on the leftover box, and expands the metadata line once so it reads 83,851 views · Jul 28, 2026 instead of 83K views · 2 weeks ago.

8. Network calls & data

EndpointUsed byWhenWhat is sent
/feeds/videos.xml (same origin)CategoryFeedwhile building a category feeda channel or playlist id
/youtubei/v1/player (same origin)UploadDateonce per video, cached in memorythe video id
channel and watch pages (same origin)PlayAll, CategoryFeed, Transcripton demandnothing beyond the URL
public translation endpointSettings language, Transcript translationwhen a non-English language is pickedthe interface strings, or the transcript lines being translated
public ratings APIThumbsDownper video, from the service workerthe video id

The service worker exists for exactly one reason: a page script may not call the ratings API cross-origin, an extension worker may.

The translation endpoint has a quota. It is Google's free one and it counts per IP address: a burst of batches — and one transcript is several, sent together — can come back 429 Too Many Requests for a minute or two, then work again with nothing changed. Until 1.6.0 a single 429 in a single batch failed the whole transcript and said only Translation failed. Since 1.6.1 every batch gets three tries with a growing, jittered wait, and anything that still fails is named in the bar itself: Translation failed · HTTP 429.

9. Privacy

  • No analytics, no telemetry, no tracking, no remote configuration.
  • No account data is read or stored. Settings, categories and translation caches live in chrome.storage.local on the machine and nowhere else.
  • Two features talk to a service other than YouTube: the translation endpoint (only for the strings being translated) and the ratings API (only a video id). Leave those widgets off and the extension never leaves the youtube.com origin.
  • The management permission is deliberately not requested — the extension cannot see or touch other extensions.

12. Known limits

  • Finished streams are recognised from a phrase that YouTube translates; fourteen languages are listed. In an interface language outside that list, past streams stay visible.
  • On playlist pages the metadata line does not carry that phrase at all, so HideLive does not reach them there.
  • The create/upload button has no stable id across YouTube versions; its rule matches by shape and is the most likely to need a touch-up after a redesign.
  • Hiding the sidebar also hides ChannelCategorizer, because that widget lives inside the sidebar.
  • Transcript translation goes through a free public endpoint with a per-IP quota. Three tries with a growing wait cover the usual burst; a quota that stays shut answers Translation failed · HTTP 429 and clears on its own in a minute or two. There is no key to buy that around, and the real caption files are not reachable — see §8.
  • Anything that depends on YouTube's own markup can break when YouTube changes it. That is the nature of the thing; the code comments name the exact selectors and why they were chosen.

13. Versioning

One work round is one patch step, rolling over at nine: 1.0.0 is the first round, 1.0.9 the tenth, 1.1.0 the eleventh. The popup shows the version in the top right, read straight from the manifest.
